
# 🏰 Warrior Castle Adventure

### A Python Text-Based Adventure Game

## 📖 Project Overview

Warrior Castle Adventure is an interactive, text-based adventure game developed using Python. Players explore a mysterious castle, collect six magical items, and attempt to defeat an evil wizard.

The project demonstrates foundational programming concepts, including dictionaries, functions, loops, conditional statements, user input validation, and inventory management.

## 🎮 Game Features

- Eight interconnected castle rooms
- Six collectible magical items
- Direction-based navigation
- Inventory tracking and item collection
- Interactive command-line gameplay
- Winning and losing conditions
- Input validation and helpful error messages
- Help and exit commands

## 🗺️ Castle Locations

- Gate House
- Royal Hall
- Training Arena
- Armory
- Library
- Alchemy Lab
- Dungeon
- Wizard Sanctum

## ⚔️ How to Play

1. Start in the Gate House.
2. Explore the castle using directional commands.
3. Collect all six magical items.
4. Enter the Wizard Sanctum to confront the evil wizard.
5. Collect all six items before entering the Wizard Sanctum to win!

### Available Commands

```text
go north
go south
go east
go west
get Map
help
exit
```

## 💻 Getting Started

### Requirements
- Python 3

### Run the Game

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

On Windows, you can also use `py main.py`.

## 🧠 Programming Concepts Demonstrated

- Python dictionaries for room navigation and item locations
- Functions for organizing gameplay logic
- While loops for continuous gameplay
- Conditional statements for decisions and game outcomes
- Lists for inventory management
- String manipulation and input validation
- Testing winning, losing, and invalid-command scenarios
